# TP2 – Estimation of Densities

**Financial Econometrics | University of Geneva (UNIGE)**

Python implementation of nonparametric density estimation methods applied to daily stock returns.

## Contents
- Arithmetic returns and descriptive moments for five stocks.
- Gaussian Kernel Density Estimation (KDE) implemented from scratch.
- Bandwidth sensitivity and split-sample comparisons.
- KDE on simulated Normal and Beta distributions.
- Parametric Normal vs. nonparametric KDE comparison.
- Bivariate and conditional Gaussian kernel density estimation.

**Tools:** Python, NumPy, Pandas, Matplotlib.

**Data:** Daily stock prices from TP1 (`TP1.xls`). Update the local file path before running the code.
