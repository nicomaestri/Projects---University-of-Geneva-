# Statistical Analysis of Time Series

**University:** University of Geneva (UNIGE)  
**Programme:** MSc in Statistics  
**Language:** R  
**Academic Year:** 2026–2027

## Overview

This folder contains R scripts, datasets, and computational exercises developed during the *Statistical Analysis of Time Series* course at the University of Geneva.

The coursework covers both theoretical and applied aspects of time series analysis, including:

- **Time Series Fundamentals:** Stationarity, ergodicity, autocovariance, ACF and PACF.
- **Trend and Seasonality:** Classical decomposition, moving averages, smoothing methods, and seasonal adjustment.
- **Linear Time Series Models:** Autoregressive (AR), Moving Average (MA), and ARMA processes.
- **Integrated Processes:** Unit roots, differencing, and ARIMA models.
- **Seasonal Models:** SARMA and SARIMA models.
- **Model Identification and Estimation:** Parameter estimation, model selection, and residual diagnostics.
- **Forecasting:** Time series prediction and forecast evaluation.
- **Nonlinear Time Series:** Threshold Autoregressive (TAR) models and nonlinear dynamics.

## Repository Structure

Each seminar has a dedicated subfolder containing R scripts, datasets, and a short README explaining the statistical methods and exercises.

The repository will be progressively updated throughout the semester.
